Entry for the [make.fun bounty "The Best Advice I Ever Got"](https://make.fun/bounty/u-pangg7-the-best-advice-i-ever-got-358cefb0).

`main.py` (stdlib-only Python 3.13) writes one sentence to `/output/entry.txt`:
the best advice the writer ever received, told as a single lived sentence —
a teacher, a failed test at twelve, and the lesson that the grade was not
the point, the trying again was.

Run it locally:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
